# 스마트클립 (SmartClip)

> 저장소 `nunco-git/ezgong` 의 `smart-clipboard/` 폴더 · 스마트공 시리즈 (https://smartgong.kr)

한글·엑셀·워드의 표와 서식을 그대로 다시 붙여넣는 Windows 클립보드 기록 관리자.
기록·메모는 외부로 보내지 않습니다. 인터넷은 새 버전 확인(깃허브에 최신 버전 번호만 물어봄)에만 쓰고, 설정에서 끌 수 있습니다. 기록은 Windows DPAPI로 암호화해 이 PC·이 계정에만 저장합니다.

## 메모 · 가리기 (1.1.0)

- **＋ 메모 추가 (Ctrl+N, 목록의 '내용' 제목 옆 ＋):** 복사하지 않고 바로 적어 두는 메모. 저장하면 ★ 고정 목록 맨 위에 들어가 기록 개수 제한으로 지워지지 않습니다. Enter로 바로 붙여넣기.
- **PW 가리기 (Ctrl+H, '내용' 제목 옆 PW):** 비밀번호처럼 남에게 보이면 안 되는 항목은 목록·미리보기에 `●●●●●●`로 표시됩니다. 제목을 붙여 두면 제목만 보이고, 찾기도 제목으로만 됩니다. 붙여넣기는 그대로 됩니다.
- 미리보기의 **👁 잠깐 보기**를 누르면 내용을 확인할 수 있고, 다른 항목을 고르면 다시 가려집니다.
- 메모 고치기: 오른쪽 클릭 → 메모 고치기 (Ctrl+E)
- **가린 항목 비밀번호 (1.1.1):** 설정 → 「비밀번호」 탭에서 정하면, 가린 내용을 **보거나·풀거나·고칠 때** 비밀번호를 묻습니다.
  - 한 번 넣으면 3분 동안(창을 숨기기 전까지) 다시 묻지 않습니다. 5번 틀리면 30초 동안 막힙니다.
  - 「가린 항목을 붙여넣을 때도 비밀번호 묻기」를 켜면 붙여넣기 전에도 묻습니다. (기본은 붙여넣기는 바로)
  - 비밀번호는 되찾을 수 없습니다. 잊으면 「잊어버렸어요…」로 가린 항목만 모두 지우고 새로 정하세요.
  - 비밀번호 자체는 저장하지 않고 확인용 값(PBKDF2)만 암호화해 둡니다.
- 모든 내용은 Windows DPAPI로 암호화되어 이 PC·이 계정에서만 풀립니다.

## 오류 · 개선 제안

사용하다가 오류나 개선할 점이 있으면 **smartgongmaster@gmail.com** 으로 알려 주세요.

## 내려받기

- **바로 받기 (항상 최신 버전):** https://smartgong.kr/download/smart-clipboard
- 설명·SHA-256이 있는 릴리스 페이지: https://smartgong.kr/download/smart-clipboard/info

**위 주소나 깃허브 공식 릴리스가 아닌 곳에서 받은 파일은 실행하지 마세요.**

### ⚠ 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면

1. 파란 창에서 **추가 정보** → **실행** 을 누릅니다.
2. **실행** 버튼이 없으면: `SmartClip.exe` 오른쪽 클릭 → **속성** → **차단 해제** 체크 → **확인** 후 다시 실행합니다.
3. 브라우저가 다운로드를 막으면: 크롬 **⋮ → 유지**, 엣지 **… → 유지 → 추가 정보 → 그래도 유지**.

### 받은 파일이 진짜인지 확인

- PowerShell: `Get-FileHash SmartClip.exe` → 릴리스 설명의 SHA-256 값과 같아야 합니다.
- 깃허브 CLI: `gh attestation verify SmartClip.exe --repo nunco-git/ezgong`

## 새 버전 배포 방법 (관리자용)

1. `smart_clipboard.py` 위쪽 `APP_VERSION` 을 올립니다 (예: `1.0.0` → `1.1.0`).
2. 커밋해서 `main` 에 올리면 깃허브 Actions가 자동으로
   빌드 → SHA-256 기록 → 빌드 출처 증명 → 릴리스(`smartclipboard-v1.1.0`) 게시 →
   홈페이지 고정 주소 갱신까지 합니다. 버전을 안 올리면 릴리스를 새로 만들지 않습니다.
3. 릴리스 설명에 바뀐 점을 적어 둡니다.

## 내 PC에서 빌드

`build_smartclip.bat` 실행 → 같은 폴더에 `SmartClip.exe`
