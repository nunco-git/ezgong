    API 키 받는 법
    1. console.cloud.google.com 에 구글 계정으로 들어가 새 프로젝트를 만듭니다.
    2. ‘API 및 서비스’ → ‘라이브러리’에서 “YouTube Data API v3”를 찾아 ‘사용’을 누릅니다.
    3. ‘API 및 서비스’ → ‘사용자 인증 정보’ → ‘사용자 인증 정보 만들기’ → ‘API 키’를 고릅니다.
    4. 만들어진 키를 복사해서 위 칸에 붙여넣습니다.
    5. 다른 사람이 쓰지 못하게, 키 설정의 ‘웹사이트 제한’에 이 앱 주소를 넣어 두면 안전해요.
    검색 한도
    • 검색 1번에 100점이 들고, 하루 한도는 10,000점이라 하루 약 100번 검색할 수 있어요.
    • 한 번 찾은 영상은 저장돼서 다시 검색하지 않아요.
    • 한도는 한국 시간 오후 4~5시경에 새로 채워져요.
