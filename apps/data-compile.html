스마트 자료 취합 시스템

스마트 자료 취합 시스템 바로 사용하기

주요 기능

  • 설문 등을 다수의 기관에서 취합할 때
  • 엑셀 파일 등록, 직접 작성 취합 가능
  • 회차별 관리 및 취합결과 간편 다운로드

이럴 때 사용하세요

  • 읍면동·산하기관에 설문조사나 실태조사 양식을 배포하고, 각자 보내오는 응답(엑셀·첨부파일 포함)을 한 곳에서 자동으로 취합할 때
  • 사회복지시설이나 보조사업자로부터 자료를 쉽고 간단하게 취합하고 싶을 때
  • 다수의 기관과 사람들에게서 자료를 받아서 간단하게 취합하고 싶을 때

안내

스마트공은 직장인을 위한 업무용 앱 모음으로, 별도 설치 없이 웹 브라우저에서 바로 사용할 수 있습니다. 다른 앱은 스마트공 메인에서 확인하세요.
