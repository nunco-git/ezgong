스마트 PDF·이미지 병합기

스마트 PDF·이미지 병합기 바로 사용하기

주요 기능

  • 압축파일 그대로 미리보기 가능
  • PDF, 이미지 확인·조정 후 병합
  • HWPX, 엑셀파일도 미리보기 가능

이럴 때 사용하세요

  • 공사 준공서류·행사 증빙자료(공문+사진+영수증)를 하나의 PDF로 묶어 결재 상신하거나, 감사·정산 자료 제출 시 첨부파일을 한 번에 정리할 때
  • 첨부파일이 있는 공문서를 한 번에 내려받아 내용을 빠르게 파악하고 싶을 때
  • 압축파일 속 내용을 압축을 풀지 않고 바로 확인하고 싶을 때
  • 각종 시스템에서 여러 파일을 한꺼번에 내려받아 내용을 확인해야 할 때

안내

스마트공은 직장인을 위한 업무용 앱 모음으로, 별도 설치 없이 웹 브라우저에서 바로 사용할 수 있습니다. 다른 앱은 스마트공 메인에서 확인하세요.
