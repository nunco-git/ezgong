스마트 파일명 관리자

스마트 파일명 관리자 바로 사용하기

주요 기능

  • 내용 자동 인식: PDF·HWPX 추출
  • 파일명 자동 생성: 규칙 조합
  • 규칙 프리셋 저장, 재사용 가능

이럴 때 사용하세요

  • PDF 파일 등 공문·증빙서류를 문서번호·수신처·날짜 등 문서 내용 기준으로 자동 파일명 부여해 문서관리를 표준화할 때
  • 행복e음이나 각종 업무 시스템에서 다운받은 파일에 신청자의 정보로 파일명을 변경하고 싶을 때
  • 각종 교육 이수증의 이수자 이름과 교육사이트, 교육과정을 엑셀파일로 정리할 필요가 있을 때

안내

스마트공은 직장인을 위한 업무용 앱 모음으로, 별도 설치 없이 웹 브라우저에서 바로 사용할 수 있습니다. 다른 앱은 스마트공 메인에서 확인하세요.
